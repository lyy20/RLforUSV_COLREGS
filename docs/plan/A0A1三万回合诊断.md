## 二、根因（奖励结构导致「不追目标」更优）

单回合收益构成（A1 末窗）：
```
超时      -25   （几乎每回合都超时）
时间罚    -20   （0.05/步 × 400 步）
距离罚    -10   （range 0.05 × 1.5/3）
安全罚     -8   （近距离通过的累积）
规则介入   -1
----------------------
小计      -64
进度奖励   +3   （18 × Δ距离/距离尺度，量级过小）
成功奖励    0   （从未触发）
出界/碰撞 -150  （一旦发生，压倒一切）
```

⇒ **「推进 1.4 km」 只值 +8 左右，而 「冒风险」 可能 −150**；
又因为**从未发生过一次成功**，策略拿不到正反馈，于是**只优化它能控制的惩罚**（少动、少转、别出界）⇒
**观察到的现象（距离不变、舵角趋零、98% 超时）正是该奖励下的最优解。**

## 三、修复方案（按杠杆排序）

| # | 措施 | 数值建议 | 依据 |
| --- | --- | --- | --- |
| **P0-1** | **课程：缩短初始距离** | 从 1.4 km 收到 **400–600 m**，成功后逐步拉远 | 直接打破「零成功」死锁，让 +100 先发生 |
| **P0-2** | **势函数塑形**（Ng et al. 1999，**不改变最优策略**） | `r += k·(d_prev − d_now)`，`k ≈ 100 / 1.4 km ≈ 70 /km` | 稠密梯度指向目标，且**理论保证策略不变** |
| **P0-3** | **降低终端风险量级** | 出界/碰撞 −150 → **−50**；或训练早期**保持安全层开启**（A1 已证 OOB 2%） | A0 出界 23.8% ⇒ 探索代价过高 |
| **P1-1** | 超时罚 −25 → **−5** | 避免「躺平」与「冒险」差距过大 | — |
| **P1-2** | 加**无进展早停**（N 步距离无改善则终止） | 省算力、促探索 | — |
| **P2** | 复核 `progress` 的 `/distance_scale` 归一化 | 当前把 1.4 km 压缩成 +8 | 量级失衡的次要来源 |

## 四、**仍然有效的部分**（不要一起否掉）

1. **安全层有效**：A1 出界 2% ✅、碰撞 0 ✅（A0 无安全层 23.8% 出界）；
2. **训练在学**：回报 −116 → −71 单调改善 ⇒ 优化器/管线正常；
3. **规则层签名正确**：A0 介入率恒 0 ✅、A1 有介入且**改动幅度下降**（0.086 → 0.035）；
4. 但 **不能判为「内化」**——任务都没完成，规则层少动只是「动得少」。
