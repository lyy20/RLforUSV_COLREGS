# 任务几何 / 场景生成：赛道现状与我们的缝隙（文献核查）

> 2026-10-13 · 目的：先确认这条路有没有人做过，再决定要不要走

---

## 一、结论先说

**「构造会遇场景」不是新赛道，已经有三四条成熟支线**；若把贡献押在场景生成或课程学习上，**会被审稿人一句话打掉**。

**但有一个缝隙是干净的**（第三节）：把**任务几何（航线 / 通道）**当作**保证规则相关状态被访问**的机制，并用**撤除屏蔽后的条件策略**验收内化。

## 三、我们真正干净的缝隙（可辩护的贡献定位）

**三个组件单独都不新，组合与结论是新的**：

| 组件 | 是否已有人做 | 我们的差别 |
| --- | --- | --- |
| 场景生成 / 会遇布置 | **是（饱和）** | 我们不做生成算法，只把布置的数学改对（用预测本船速度） |
| 课程 / 难度调度 | **是** | 我们**明确不用难度爬升**（有形式化理由：破坏回合内平稳性） |
| 规则合规 | **是**（2402.08502 用时序逻辑约束） | 我们的机制是**规则教师 + 模仿损失**，且**目标函数里不写规则** |
| **任务几何保证 Ω 被访问** | **未检索到直接对应工作**（最近的是合规航线规划，但目的不同） | **几何是训练信号的保障，不是合规手段** |
| **撤除屏蔽后的条件策略评估** | 部分（2402.08502 是可证明合规，不是撤除后测量） | 内化定义为运行期撤除外挂后仍合规 |

**可写进论文的定位句**（建议）：

> 与用时序逻辑约束保证合规的工作（如 2402.08502）不同，本文不把规则写成约束或奖励，而是让**规则教师以模仿损失的形式**传递规则；
> 与主流场景生成 / 课程学习工作不同，本文**不追求生成更难的场景**，而是用**任务几何**保证规则相关状态被访问；
> 并用**撤除屏蔽层后的条件策略**作为内化的验收口径。

**顺带一条负面结果也可以写**（这是原创发现）：

> 当奖励使回避成为最优时，规则相关状态的访问率会随训练**衰减约 90 倍**（发声率 ÷6.8 × 修正幅度 ÷13.4），
> 教师信号随之消失——这是外挂式规则学习的**结构性失效**，而非样本量问题。

## 五、CTRIP 接口：航点输入怎么预留（代码落点已查）

**代码现状（已核实）**：

| 位置 | 现状 |
| --- | --- |
| `usv_tracking_base.py` L191 / L212 | 奖励与距离**只读 `world.landmarks[0]`** |
| L1258 | `world.landmarks` 生成 `num_landmarks*2` 个对象（后半是估计器占位） |
| L1107 | 默认 `num_landmarks=1` |

⇒ **最省事的接口设计**（不动观测契约、不动奖励代码）：

| 设计 | 说明 |
| --- | --- |
| **保持单一活动目标语义** | 观测永远是当前活动航点的相对位置 ⇒ **dim 63 不变** |
| **新增航点序列参数** | 例如 `route_waypoints_km = [(x1,y1), (x2,y2), ...]`；**长度 1 时行为完全等于现在**（向后兼容） |
| **到达即推进** | 与活动航点距离小于到达半径时，把 `landmarks[0]` 的位置改到下一个航点（可顺带重置进度奖励基准） |
| **CTRIP 对接点** | CTRIP 若输出一条航路（航点序列），直接喂进这个参数；本工作负责沿航路把规则内化 |

**为什么这是能共同介绍的形态**：

| 论文 | 负责 | 接口 |
| --- | --- | --- |
| **CTRIP（上一篇）** | 生成 / 跟踪航路（快速抵达） | 输出**航点序列** |
| **本工作** | 沿航路实现**规则内化** | 消费**同一航点序列** |

⇒ 两篇共用一套（航点 → 任务）的输入契约，**在毕业论文里可自然串成一条线**。

**代价评估**：这是静态场景配置，不涉及回合内修改 ⇒ **不触碰平稳性红线**，也不与你的两条反驳冲突。

## 六、一句话总结

> 场景生成这条路**已经饱和**（海事有 AIS 生成式，AD 有综述）；课程学习也有人做过；**规则合规还撞上时序逻辑那篇**；
> 我们的干净缝隙是：**任务几何只作曝光保障，规则由教师模仿传递，内化用撤除屏蔽后验收**——再加那条 **90 倍信号衰减的负面结果**。
> 航点接口按「单一活动航点 + 航点序列推进」实现：**向后兼容、不动观测、不破平稳性**，正好给 CTRIP 留位。
