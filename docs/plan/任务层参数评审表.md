# 任务层参数评审表（供你逐项决定，2026-10-10）

> 用途：你逐项审阅并决定改/不改。每行给出：现值 → 作用 → 问题 → 候选 → 我的建议。
> 参数层已完成（V4），本文只谈任务层。

## 零、本轮新增的关键证据（影响任务层多处）

| 证据 | 数值 | 影响 |
| --- | --- | --- |
| **USV 在 reset 时静止** | 速度模长 = **0.000 m/s**（t=0） | 生成器按恒定速度设计会遇，但 USV 随后加速到约 1.4 m/s ⇒ **设计 CPA 不成立** |
| **设计 vs 实际 DCPA** | 设计中位 **58 m** → 实际最小距离中位 **165 m（2.66×）**；仅 **21%** 落在设计附近 | 会遇**没有真正发生到设计距离** |
| 设计 DCPA 分布异常 | 中位 58 m（均匀采样应为 35 m） | 生成器实际采样偏向区间上沿，**需查** |

⇒ 结论：**「设计会遇」目前只兑现约 1/5**。任务层必须先定「如何保证会遇真的发生」。

## 四、奖励类（18 项）

| 项 | 现值 | 问题 |

| `reward_progress_weight` | 18.0 | 速度翻倍后单位时间前进量翻倍 ⇒ 相对量级已变 |
| `reward_collision` / `reward_out_of_bounds` | 150 / 150 | 同权；出界问题缓解后需再平衡 |

| `reward_safety_weight` / `boundary_weight` | 10 / 8 | 与规则/边界风险尺度相关 |
| `reward_intervention_*` | 0.02 / 0.10 | 安全层介入惩罚，**与内化目标直接相关（实验变量）** |
| 其余（rudder/yaw/smooth/time/range/safe_clearance） | — | 控制代价类，量级随速度变化 |

**建议**：**先不动奖励**，用 V4 跑 400–1000 回合拿基线分布，再按各分量贡献占比重标定（一次改太多无法归因）。
