## 反驳 1：让靶子会飞 = 可观测实体无条件闪现？观测还连贯吗？学到的策略还对吗？

### 结论：一半对，一半不对。**v1 的「全知连续重瞄」版本错了，我撤回它。**

要区分两件被混在一起的事：

| 做法 | 位置连续？ | 观测连续？ | 物理可行？ | 评价 |
| --- | --- | --- | --- | --- |
| **位置闪现**（把船瞬移到新位置） | ✗ | ✗ | ✗ | **确实是作弊，你说得对** |
| **速度重解**（位置连续，只改航向 / 速度，且受加速度与转向速率限制） | ✓ | ✓ | ✓ | 这就是真实船舶在做的事：**改向** |

⇒ 所以「重瞄」若写成**每步全知重算**，它确实会退化成你说的问题：
1. **对手变得不真实地敏捷**（现实中没人能预知你的动作）⇒ 策略学到的是对付一个超敏捷对手 ⇒ **迁移不到真实交通**；
2. 若每步大幅跳变速度，**观测到的加速度本身就是个伪特征**，策略会去拟合它。

**所以 v1 的这一版我撤回。** 但它不等于「根因修复不可行」——可行的版本是下面两个，都**不构成闪现**：

### 修正 1-A：把校正放在「设计阶段」而不是「回合中」（最干净）

- 布置会遇时，不再假设本船「**立刻以名义巡航速度直线**」，而是用**当前策略短程 rollout 预测出的本船平均速度向量**去解算目标初始状态；
- **回合中不做任何修改**：目标仍然恒定航向 / 航速（或原有的运动模式）⇒ **环境在回合内是平稳的、物理不变、观测连续**；
- 改变的只有「**把靶摆在哪**」，不改变「靶怎么动」。

### 修正 1-B：失效会遇的「重新布置」发生在**观测盲区**里

如果会遇确实已经跑废（例如目标早已远离本船航路），需要补一次，则**只在观测半径之外**重新布置：

| 量 | 本配置值 |
| --- | --- |
| 障碍观测半径 ob_range | **0.9 km** |
| 地图半边长 | **1.5 km** |
| **盲区环带**（0.9–1.5 km）占地图面积 | **≈ 50%** |

⇒ 在环带里补一个目标，**策略当前根本观测不到**；等它进入观测范围时，就是「**一艘船从远处驶来**」——这正是真实场景，不构成闪现。

**但必须加三条硬约束**（否则仍会被质疑）：
1. **每个回合的重布置次数有上限**（例如 ≤2 次），避免变成「无限的靶」；
2. **重布置的目标必须以真实航向 / 航速进入**（不能凭空对准你）；
3. **训练与评估使用同一套船舶行为模型**（行为一致性），只允许「**换摆位**」，不允许「**换物理**」。

## 反驳 2：自适应生成 = 环境不稳定、丢泛化、还可能把追踪搞坏？

### 结论：**完全对。纯「贴着你出题」的对抗版本是错的，我也撤回。**

你指出的三个问题，恰好就是文献里对抗式环境设计的已知失效模式：

| 你的担心 | 为什么会发生 | 文献里的对策 |
| --- | --- | --- |
| **环境不稳定** | 生成分布随策略一起动 ⇒ 目标函数非平稳 ⇒ 灾难性遗忘 | Prioritized Level Replay 明确采用「**优先级 + 新鲜**混合」并对分数做**陈旧化** |
| **丢失丰富性** | 只保留「刚好难」的窄带 ⇒ 覆盖面塌缩 ⇒ 泛化变差 | 保留**原始分布为主体**，自适应只做**小幅补足** |
| **难度过冲、追踪被搞坏** | 对抗目标（最大化义务密度）没有上界 ⇒ 推到学不会的边界 | 需要**难度上限**与**任务性能约束** |

⇒ **修正后的 P2 不是「难度爬升」，而是「布置校正 + 按真实交通校准」**：

| 修正点 | 做法 |
| --- | --- |
| **主体不变** | **大部分回合仍从原始丰富分布采样**（对遇 / 交叉 / 追越权重、DCPA / TCPA 范围、速度包线全部保留）；自适应只处理「**本应成立的会遇却没成立**」的那部分 |
| **只改摆位，不改难度** | 自适应旋钮只有**几何布置**（让设计好的义务**真的发生**），不提高目标速度、不缩短 DCPA 设计值、不增加对手数量 |
| **目标值来自真实交通** | 义务密度 / 会遇频率的目标**不是「越高越好」**，而是**按 AIS 实测交通统计校准**（本项目已有 `calibrate_ais_distribution.py` 与 AIS 校准工作） |
| **覆盖约束** | 会遇类型配比、DCPA / TCPA 分布、速度包线必须与原分布**统计一致**（可做分布检验） |
| **追踪代价进约束** | 把追踪成功率**当作约束**（例如不低于 A0 的一半），不是当作可以牺牲的量 |
