# 奖励函数设计：论文表述 + 汇报文本（2026-10-11）

## 一、可写入论文的正式表述（方法章节 · 奖励设计）

### 3.X 奖励设计原则

本研究的目标是在**长距离目标追踪**任务中实现**海事规则内化**，即策略在撤除安全过滤层后仍能履行 COLREGs 义务。
据此，奖励函数遵循三条原则：

**（1）规则不进入奖励。** 如果将 COLREGs 的具体条款（会遇类型、让路义务、转向幅度）直接编码为奖励项，
则策略学习到的是"对奖励条款的拟合"，而非规则内化；且规则细节随会遇几何变化，奖励形式难以穷尽。
因此本文将规则学习交由两个独立部件承担：**规则动作屏蔽层**（训练期约束）与**规则教师 + 模仿损失**（策略学习）；
奖励函数仅保留**安全底线**（碰撞、越界）与**任务引导**（抵达、效率）。

**（2）量级分层。** 设成功奖励为 R_succ，则要求：
稠密塑形项的**全程累计跨度**不超过 0.5·R_succ；
**单步稠密项之和**不超过 0.02·R_succ；
**危险终止项**不低于 1.0·R_succ。
前两条保证终端任务在时间尺度上占主导（避免策略"刷稠密分"），第三条保证安全**不可与成功交换**。
该约束将权重确定由经验试凑转变为可复核的设计条件。

**（3）塑形须保策略不变。** 长时域任务中稀疏终端奖励不足以提供有效梯度，
故引入距离势函数塑形。依据 Ng 等（1999）的势函数塑形定理，取 Φ(s) = −k·d(s)（d 为目标距离），
塑形项为 γ·Φ(s') − Φ(s) = k·(d − γ·d')，其对各策略的回报仅相差常数 −Φ(s_0)，
**不改变最优策略集合**；在回合截断处取 Φ(s_terminal) = 0，以保证有限时域下的望远镜求和仍然闭合。

### 3.X+1 奖励项定义

奖励由**四项终端项**与**四项稠密项**构成：

- 终端：成功 R_succ = +200；超时 −20；碰撞 −200；越界 −200。
- 稠密：
  - 势函数塑形项 k·(d_prev − γ·d_now)，k 取使全程跨度约 0.5·R_succ（1.2 km 航程取 k ≈ 85 /km）；
  - 时间步罚 c_t = 0.02；
  - 风险预警项 −exp(−α·(d_safe − DCPA))，仅当 DCPA < d_safe 时生效（取最近他船）；
  - 边界预警项 −w_b·((d_safe^b − clear)/d_safe^b)^2，w_b = 3；
  - 执行平滑项（动作、转艏率、舵角变化三项合并）系数 0.05。

设计上**删除了恒定距离罚**（range）：其语义与势函数塑形重复，会造成同一目标的双重信号。

### 3.X+2 与既有工作的关系

本文奖励结构与文献中的三类做法一致而有所取舍：
（i）文献普遍采用**风险几何项**（如按 DCPA 的门控指数惩罚），本文保留但将其**限制为有界预警**，
以避免与规则屏蔽层重复惩罚；
（ii）文献常采用**子任务分解**（路径项与避碰项并列），本文将"路径"以**势函数塑形**形式实现，
从而获得策略不变性保证；
（iii）文献中权重多依赖实验调节，且已有工作明确指出"奖励权重与切换阈值未做全局优化"，
本文通过**量级分层约束**给出可推导的初值，并以消融实验验证各项必要性。

### 3.X+3 消融设计

为验证奖励结构，设置四组消融：（A）移除势函数塑形；（B）移除风险与边界预警；
（C）终端量级缩放 0.5× 与 2×；（D）移除执行平滑项。评价指标以**内化指标**（撤除屏蔽层后的合规比与反向动作比）为一等，
成功率为二等。

## 二、最直白的汇报文本（可直接口头讲）

> 以前的奖励有 13 项，互相打架，还把"规则答案"偷偷写进了奖励里，
> 所以策略学会的是**刷分和躺平**，不是完成任务，也不是内化规则。
>
> 现在压缩成 8 项、分三层：
> **第一层是生死**——成功 +200，碰撞/越界 −200，超时 −20，成功必须压倒一切；
> **第二层是引路**——用距离势函数塑形（有理论保证：不改变最优策略），全程跨度只有成功的一半，
> 负责告诉策略"往哪走"，但永远不能盖过"到达"；
> **第三层是提醒**——风险预警和边界预警都很小，只提前提示，不重复惩罚；
> **规则本身不再进奖励**，交给独立的规则层和模仿损失去学——这才是"内化"该待的地方。
>
> 另外，**距离不再为了成功率缩短**：训练就放在 1 公里以上的长距离，
> 因为**短距离场景是长距离场景的子集**，反过来不成立；短距离只能当课程的中间档，最后一档必须是最长档。
>
> 一句话：**奖励是让策略学得动的装置，不是规则的编码本；终端定生死，塑形引路，预警提醒，规则另学。**
