# 正式实验矩阵（基于冻结的 V6 环境，2026-10-10）

> 环境层已冻结，见《环境层声明与冻结》。本文只给**可执行矩阵**：臂 / 变量 / seed / 成本 / 指标 / 验收。

## 一、臂定义（单变量原则：每臂只差一个开关）

| 臂 | 名称 | 与父臂的差异 | 目的 |
| --- | --- | --- | --- |
| **A0** | 纯 SAC（无安全层、无模仿） | `agent_colregs_action_filter_enabled=false`、`RULE_BUFFER_ENABLED=False` | 内部化上界对照 |
| **A1** | 仅安全层 | filter=true、`RULE_BUFFER_ENABLED=False` | 借来的合规基线 |
| **A2** | 安全层 + 规则模仿（主臂） | filter=true、rule buffer=true、`RULE_IMITATION_WEIGHT=0.05` | 主方法 |
| **A3** | 模仿权重消融 | 仅 `RULE_IMITATION_WEIGHT=0.20` | 权重敏感性 |
| **A4** | 模仿 + DAgger（可选） | 仅 `DAGGER_ENABLED=true` | 教师聚合消融 |
| **E0** | 环境对照（可选） | 仅 `encounter_generation_mode=0` | 环境层贡献 |

## 二、矩阵（seed × 回合档）

| 层级 | 臂 | seed | 回合 | run 数 | 说明 |
| --- | --- | --- | --- | --- | --- |
| **第一阶段（筛选 100k）** | A0, A1, A2, A3 | 1,2,3 | 100k | **12** | 看方向与方差，淘汰无效臂 |
| **第二阶段（正式 500k）** | 第一阶段前 2 名 | 1,2,3 | 500k | **6** | 出论文主结论 |
| 可选 | A4 / E0 | 1,2,3 | 100k | 6 | 消融 / 环境贡献 |

## 三、成本（实测 2.97 s/回合；**2 进程并发为上限**）

| 回合档 | 单 run 墙钟 | 12 run（2 并发） | 6 run（2 并发） | 磁盘/run |
| --- | --- | --- | --- | --- |
| 100k | **3.4 天** | **20.6 天** | 10.3 天 | ~0.2 GB |
| 300k | **10.3 天** | 62 天 | 31 天 | ~0.6 GB |
| 500k | **17.2 天** | 103 天（不现实） | **51.7 天** | ~1.0 GB |

- `POLICY_SAVE_INTERVAL=1000` ⇒ 500k 回合产生 500 个 checkpoint（≈0.5 GB）；建议改 5000（100 个，省 80% 磁盘）；
- TB 日志已精简到 29 个标量，50 万回合约 **≤0.3 GB/run**；
- **禁止 3 进程并发**（12 GB 显存会 CUDA 报错），**必须错峰启动**（间隔 ~40 s）。

## 四、每臂要读的指标（29 标量中的核心 9 个）

| 指标 | 含义 | 关注 |
| --- | --- | --- |
| `agent0/rule_filter_active_rate_episode` | **教师发声率** | 是否稳定 ≈14%（环境供给） |
| `rule_buffer/size`、`fill_ratio` | 规则样本量 | 持续增长（>50% 填充） |
| `agent0/mean_episode_rewards` | 任务回报 | 收敛平台 |
| `done_reason_success_episode` / `timeout` | 任务成败构成 | 成功率 / 超时率 |
| `agent_collision_episode` / `outofworld` | 安全 | 出界率应下降（V6 当前 ≈2.75%） |
| `action_chain_constrained_to_rule_mean` | 规则层改动幅度 | 规则层是否起作用 |
| `action_chain_rule_to_smoothed_mean` | 执行层平滑 | α=0.35 下 ≈0.45–0.48 |
| `actor/critic/alpha/rule_imitation_loss` | 训练健康（**V6 新增**） | 无发散、模仿损失下降 |
| `min_clearance_mean_episode` | 会遇最近距离 | 安全裕度 |

## 五、训练后评估协议（判据已冻结）

| 变体 | 用途 | 命令要点 |
| --- | --- | --- |
| `sac`（`policy_only`，**关安全层**） | **内化判据**：策略独立合规能力 | `--variants sac --episodes 80 --no-gif` |
| `sac_colregs`（`assisted`，开安全层） | 系统级性能 | `--variants sac_colregs` |

报告用 **M13 六项联合报告**（`evaluation/joint_report.py`）：成功率/超时率、零事件率、过滤介入率、内化率、A0 合规比、A0 反向比。
**必须写明**：评估 checkpoint（回合数）、seed 数、事件数、CI。

## 六、验收判据

| 阶段 | 判据 |
| --- | --- |
| 第一阶段（100k） | ① 教师发声率 ≥10%；② loss 有限无发散；③ 出界率 ≤5%；④ A2 相对 A1 有正向趋势 |
| 第二阶段（500k） | ① 3 seed 回报曲线进入平台；② **关安全层**内化率 A2 > A1（带 CI）；③ 反向动作比 A2 < A1 |

## 七、配置生成

```
命名：V6_<臂>_S<seed>.txt   例：V6_A2_S1.txt
基于：SAC_3DOF_ENTITY_ENCODER_0911_V6.txt（冻结）
每份只改：TRAINING_RUN_NAME / SEED / 臂对应的 1~2 个开关 / number_of_episodes / POLICY_SAVE_INTERVAL
```

**改动前必须过冲突登记表**（`configs/parameter_conflict_registry.json`）。

## 八、执行纪律

1. **同一时刻最多 2 个进程**，错峰启动；
2. **退出码不可靠**（本项目多次出现「跑满但 exit=1」）⇒ 以产物为准（TB 标量、回合计数）；
3. 每 run 结束**立刻归档**：`docs/results/<臂>_<seed>.json` + 一行 commit；
4. 内存留出 ≥8 GB（训练占用 60–66%）；
5. 阶段之间**冻结配置**，禁止边跑边改（否则归因失效）。
