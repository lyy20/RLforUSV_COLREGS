# 船舶身份参数集方案（动态船多身份建模用）

> 目标：给动态船赋予**不同真实船型身份**，让会遇分布更接近现实交通；所有参数须**可溯源**。
> 依据分级：**A 权威标准**｜**B 实测数据**｜**C 同行实现**｜**D 任务设定**（必须声明）。

## 三、3DOF 融合公式（把船型身份变成可执行约束）

一阶 Nomoto：`r(s)/δ(s) = K / (1 + T·s)`。

- 稳态：`r_ss = K · δ` ⇒ **max_yaw_rate = K · max_rudder_angle**
- 角加速度上限：`r_dot_max ≈ K · rudder_rate`
- 回转直径 ≈ `2π v / r_ss`，用于与 IMO ≤5L 互相校核

| 项目参数 | 由身份导出 |
| --- | --- |
| `usv_max_rudder_angle_deg` | 35°（已一致） |
| `usv_max_rudder_rate_deg_s` | 取船型 `rudder_rate`（商船 2.5–5，小艇 20–30） |
| `usv_max_yaw_rate_deg_s` | `K · δ_max`（商船 3–8 °/s，小艇 30–60 °/s） |
| `target_max_accel_mps2` | 船型 `accel`（商船 0.02–0.05，小艇 0.5–1.5） |
| `dynamic_obstacle_*_size` | `L / 1000` km（半径 = L/2） |

## 四、IMO MSC.137(76) 约束（反向校核，防拍数）

| 指标 | 要求 | 用途 |
| --- | --- | --- |
| 回转直径 | **≤ 5L** | 校核 K 与转艏率 |
| 纵距 advance | ≤ 4.5L | 同上 |
| Z 形首/次超越角 | 按 L/V 分档有上限 | 校核舵速与角加速度 |
| 停船距离 | ≤ 15L | 校核减速能力 |

## 七、必须先做的核实清单

1. 为第二节每个「待核实」找到可引用出处（IMO/船级社/基准船型/公开论文）；
2. 确认 K、T 的船型对应（商船 vs 小艇差一个数量级）；
3. 校核 `K · δ_max` 是否满足 IMO 回转直径 ≤5L；
4. 落成 `vessel_identities.yaml` 并在环境侧按身份抽样接入。

> **诚实声明**：除两项「已核实」外，本文船型数值**尚未逐条取得引用出处**；写入配置前必须完成第七节核实。
