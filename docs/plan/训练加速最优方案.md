## 二、三个改动（按收益排序）

### L1 · 规则热路径去 numpy 化（`safety/colregs.py`）

| 改动 | 原因 | 等价依据 |
| --- | --- | --- |
| `wrap_to_pi` / `vector_heading` / `_relative_metrics` 改用标量 `math` | 被调 **453 次/步**，每次都在做标量级 numpy 派发 | `math.pi == np.pi`；运算顺序与公式不变；digest 验证一致 |

**收益**：numpy 派发调用 ~306k → ~204k（/150 步）。

### L2 · 规则缓存改「按实体状态键 + 按步清空」（`multiagent/core.py`）

| 改动 | 原因 |
| --- | --- |
| 报告缓存键 =（ownship 状态键, target 状态键）；状态缓存键 = 实体状态键；仅步号变化时清表 | 原实现**任一实体移动就整表清空** ⇒ 每步 `colregs.evaluate` 被调 **60 次**（≈12 轮全量重算） |
| 状态键含 `pos/vel/size/heading/role/colregs_compliant` | 覆盖 `vessel_state_from_entity` 全部输入 ⇒ 命中即等价 |

**收益**：`vessel_state_from_entity` 10,819 → **7,689**（/150 步）。

### L3 · 去掉热路径 O(n) 线性查找（`multiagent/core.py`）

| 改动 | 原因 |
| --- | --- |
| 新增 `_agent_index_map()`（`id(entity) -> 下标` 缓存） | `_entity_heading` 每步被调 **124 次**，每次两次 O(n) 扫描 |
