| 批评 | 我的判定 | 理由 |
| --- | --- | --- |

## 二、四个候选创新点（附新颖性状态与威胁文献）

### 候选 1（推荐）：**曝光下界保证** —— 把可学性变成可证的性质

**核心命题**：设 μ_π 为策略 π 在场景族 S 下诱导的状态分布，Ω 为规则义务状态集。则

```
固定场景族 S_free（会遇随机散落）：  inf_π μ_π(Ω) = 0     ← 回避型策略可以完全不进 Ω
设计场景族 S_geo（会遇压在必经航路上）： inf_π μ_π(Ω) ≥ c > 0   ← 与策略无关的下界
```

**为什么这是贡献**：它把「规则学不动」从**样本量问题**变成**可控的设计条件**；
而且这是**与策略无关的保证**（不含回合内改环境 ⇒ 不破坏平稳性）。

**新颖性状态**：检索未发现直接对应工作；最近的是「合规航线规划」（目的不同：规划合规路径，不是保证训练曝光）。

### 候选 2（推荐）：**有效规则信号预算 N_eff 及其预测能力**

```
N_eff = μ(Ω)  ×  采样频率  ×  修正幅度(intervention magnitude)
```

**可检验的预测**：最终内化程度由 N_eff 决定；实测我们的 N_eff **衰减约 90 倍**（发声率 ÷6.8 × 幅度 ÷13.4）。
⇒ 用它**预测**各臂的最终合规率（跨臂验证）⇒ 把调参变成**资源配置**。

**为什么这是贡献**：给出**效率对比的公平轴**（达到同一合规率所需的**环境步数**与**教师查询数**）。

### 候选 3（推荐）：**规则是条件约束，不是奖励** —— 把设计信条升级成命题

**命题**：规则义务是**条件式**的（仅在 Ω 上生效）。因此：

| 编码方式 | 后果 | 可测证据 |
| --- | --- | --- |
| 写进奖励（软约束） | 最优策略在**全状态空间**被改变 ⇒ 追踪被牺牲；且约束**不保证**成立 | 需要一个**奖励塑形基线臂**来量 |
| 用时序逻辑/硬约束 | 合规有保证，但**策略本身没学到规则**（外挂式） | 与 2402.08502 的差异点 |
| **本文：条件约束 + 蒸馏通道** | 约束只压 Ω，追踪不被无谓牺牲 | A0 vs A1/A2 的追踪对比 |

**为什么这是贡献**：它把「规则不进奖励」从**设计口味**变成**可证命题 + 可测对比**。

### 候选 4（可选）：**可验证的内化接口**（义务模式显式化 + 抽样认证）

让策略显式输出「当前义务模式」（直航 / 让路 / 无义务），在 Ω 上做**覆盖抽样认证**，给出内化的**置信下界**而不是单点数值。
新颖性：与 2402.08502 的「可证明合规」不同——他们靠约束，我们靠**学习 + 认证**。

## 三、建议的论文主论点（一句话组装）

> **规则内化 = 在义务集 Ω 上学习一个条件策略。**
> 因此论文给出三件事：
> ① **为什么规则不能进奖励**（条件约束命题 + 奖励塑形基线对比）；
> ② **如何保证 Ω 被访问**（曝光下界保证，与策略无关、不破坏平稳性）；
> ③ **内化速度由什么决定**（N_eff 预算，跨臂可预测），并用**撤除屏蔽后的协议**验收。

⇒ 三个 claim 各自**有实验、有对比轴**，不再是「我们用了一个成熟手段」。

## 四、效率对比怎么做（直接回应『无法证明更高效』）

**基线（必须至少三条）**：

| 基线 | 代表既有做法 | 链接 |
| --- | --- | --- |
| **奖励塑形**（把规则写成惩罚项） | 经典 COLREGs 奖励塑形 | https://arxiv.org/abs/1511.05952（PER，仅作方法参考） |
| **仅屏蔽**（无教师通道） | 屏蔽式安全 RL | https://arxiv.org/abs/1708.08611 |
| **时序逻辑约束**（若能复现） | 可证明合规 | https://arxiv.org/abs/2402.08502 |
| **自适应屏蔽** | 屏蔽松弛类工作 | https://arxiv.org/abs/2506.11033 |

**对比轴（三条，都可量化）**：

1. **达到同一合规率所需的环境步数**（横轴 env steps，纵轴撤屏蔽后的 Ω 合规率）；
2. **达到同一合规率所需的教师查询数**（我们的教师是解析函数，查询便宜 ⇒ 这是我们的强项，但要公平说明）；
3. **泛化**：训练用 HO + CR，测试用**未见的追越（OT）**与未见几何 ⇒ 检验是否学到规则而不只是拟合场景。

**预期结论（可证伪）**：奖励塑形基线在追踪上受损且合规不保证；仅屏蔽基线合规率不随训练上升；
我们在**相同环境步数**下达到更高合规率，且泛化到未见会遇类型。
