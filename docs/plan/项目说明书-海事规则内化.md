## 1. 这个项目要干什么

### 1.1 一句话

> 让无人艇在**长距离追踪目标**的路上，**自己就会按海事规则避让**——而不是靠一个外挂程序替它做决定。

### 1.2 什么叫内化（本文最重要的定义）

项目组口径：

> **完全内化 = 去掉过滤器后，仅仅依靠策略输出的原始锚作 + 一定的物理约束，即可实现遵循海事规则。**

翻成白话：

| 阶段 | 谁在做避让决定 | 问题 |
| --- | --- | --- |
| 传统做法 | **过滤器（副驾驶）**抢方向盘，策略只管追目标 | 规则不在智能体里，换船 / 换场景就崩 |
| **本项目目标** | **策略（学员）自己**做决定，教练只在训练期教 | 规则成为策略的性质 ⇒ 可迁移、可解释、可发表 |

### 1.3 判据（怎么算做到了）

**一等指标（决定论文成败）**：

1. **撤除过滤器后的合规率**：评估时关掉安全过滤器，统计策略自身动作的规则合规比例；
2. **反向动作比**：统计策略在应当让路时输出抢越 / 反向动作的比例；
3. **最小会遇距离（DCPA）分布**：撤除过滤器后是否出现危险接近。

**二等指标（载体是否成立）**：追踪成功率、目标距离、超时率。

> 为什么分等：**追踪任务在上一篇 CTRIP 已解决**。若本研究以成功率为主指标，等于重复劳动；**内化才是本研究要回答的问题**。

## 2. 为什么这么干（四条设计公理）

这四条不是参数选择，是**方法论层面的取舍**，每一条都决定了后面的实现。

### 公理 1：规则不写进奖励

- **理由**：把规则条款编码成奖励项 = **把答案写进题面**。策略学到的是拟合奖励里的规则式，而不是内化规则；而且规则随会遇几何变化，奖励项穷举不完。
- **因此**：规则由**独立部件**承担——① 训练期的**规则安全过滤器**（只防撞、不评价合规）；② **规则教师 + 规则经验池 + 模仿损失**（把标准答案喂给策略）。
- **奖励只保留**：任务引导 + 安全底线。

### 公理 2：训练距离必须长，不能为成功率缩短

- **理由（泛化方向性）**：**短距离场景是长距离场景的子集，反之不成立**。用短距离硬凑成功率，等于**牺牲最终泛化**去换前几万回合的曲线好看。
- **因此**：训练就在 **1.0–1.2 km（约 5 分钟）**；短距离只能作为课程的**中间档**，**最后一档必须是最长档**。

### 公理 3：一等指标是内化，成功率二等

- 见 1.3。这条直接决定了规则信号（教师）在系统中的**地位是一等**，而成功奖励只需够用。

### 公理 4：奖励量级分层（可复核，不靠拍数字）

设成功奖励为 R_succ，则要求：

| 约束 | 含义 | 当前取值 |
| --- | --- | --- |
| 稠密塑形**全程跨度 ≤ 0.5 × R_succ** | 防止策略刷稠密分 | 60/km × 1.1 km ≈ +66（含 γ 残差，见 6.2） |
| **单步稠密项之和 ≤ 0.02 × R_succ** | 保证终端任务在时间尺度上占主导 | 时间 0.02 + 风险 2 + 边界 2（上界） |
| **危险终止 ≥ 1.0 × R_succ** | 安全不可与成功交换 | 碰撞 120、越界 120 ≥ 成功 100 |

> 这套约束的价值：把权重怎么定从**试凑**变成**可复核条件**，是本文可写进论文的贡献点之一。

## 3. 系统长什么样

### 3.1 三层结构

```
                  ┌──────────── 训练期才有 ────────────┐
                  │                                    │
  观测 s ─▶ 策略 π ─▶ a_raw ─▶[物理约束]─▶ a_con ─▶[规则过滤器]─▶ a_rule ─▶[平滑 EMA]─▶ 执行
                  │                                      ▲                │
                  └──── 模仿损失 L_rule ◀──── 规则经验池 ◀──── 规则教师 a_teacher
```

| 环节 | 作用 | 训练期 | 评估期（内化检验） |
| --- | --- | --- | --- |
| 物理约束 | 舵角 / 推力限幅、动力学可行性 | 开 | **开**（属于必要的物理约束） |
| 规则过滤器 | 依 COLREGs 修正动作，**防止撞船** | 开 | **关**（要检验策略自己会不会） |
| 规则教师 + 经验池 + 模仿损失 | 把规则标准答案灌进策略 | 开 | 关（不参与推理） |
| 动作平滑 EMA | 执行平顺（实船可用） | 开 | 开 |

### 3.2 动作链与可观测诊断

策略输出的动作依次经过四段，每段的改动量都被记录成诊断指标：

raw → constrained → rule → smoothed → actuator

这让我们能区分：**是物理约束在改动作，还是规则层在改动作，还是平滑在改动作**——这是规则到底起没起作用的直接证据。

### 3.3 观测契约

- 名称：`3dof_body_frame_v2_action_state`；维度 **63 = 15 + 7×4 + 5×4**（4 个动态槽 + 4 个静态槽）；
- 含义：本船状态 + 目标 / 障碍在**本船体坐标系**下的相对状态 + 动作链状态；
- 意义：**体坐标系**意味着同一个世界场景，随本船朝向不同、观测不同——这决定了后续若要人造状态，必须**同时造出合法的观测**（见 7.3）。

### 3.4 五个实验臂（单变量对照）

| 臂 | 规则过滤器 | 规则经验池 | 模仿权重 | DAgger | 回答什么问题 |
| --- | --- | --- | --- | --- | --- |
| **A0** | 关 | 关 | — | 关 | 纯 SAC 的上限（任务能不能学会） |
| **A1** | 开 | 关 | — | 关 | **只加安全层**：任务完成受不受影响 |
| **A2（主臂）** | 开 | 开 | **0.20** | 关 | 规则教师能不能教会策略 |
| **A3** | 开 | 开 | **0.50** | 关 | 模仿权重消融（教得更狠会怎样） |
| **A4** | 开 | 开 | 0.20 | **开** | DAgger 聚合能不能提高模仿效率 |

配置：`V6_A0_S1.txt` ~ `V6_A4_S3.txt`（5 臂 × 3 种子 = **15 个**），每个 10 万回合。

## 5. 已经做到什么程度（第一轮实跑）

**规模**：3 个臂（A0 / A1 / A2 的第 1 号种子）各跑到 **6.5–6.8 万回合 / 约 20 小时**；无 NaN、loss 收敛、约 2450 回合每小时。

### 5.1 结果总表（首窗 → 末窗）

| 指标 | **A0 纯 SAC** | **A1 仅安全层** | **A2 安全层 + 模仿** |
| --- | --- | --- | --- |
| 回合数 | 68,072 | 67,779 | 65,617 |
| **追踪成功（每 500 回合窗口）** | **0 → 32~57（约 6~11%）** | **0 → 0（全程零）** | **0 → 0（全程零）** |
| 回报 | −19.7 → **+18.9** | −31.2 → **+21.5** | −27.5 → **+21.4** |
| 目标距离（km） | 1.09 → **1.03** | 1.10 → **1.053** | 1.10 → **1.116（在增大）** |
| 越界（每 500 窗口） | 45~99 → **0** | 61~86 → **3~4** | 62~103 → **1** |
| 碰撞 | 0 | 0 | 0 |
| **教师发声率** | 0（未开） | **0.187 → 0.0275** | **0.171 → 0.0313** |
| **教师修正幅度** | 0（未开） | **0.123 → 0.0092** | **0.115 → 0.0129** |
| 规则池 | — | — | **10 万条（已满）** |

### 5.2 三条结论

**结论 1：任务本身可学。** A0（不加任何规则机制）在同样环境里达到 6~11% 成功率、回报转正、越界压到 0 ⇒ **环境、代码、奖励没有坏**。

**结论 2：安全层把任务完成堵死了。** A1 / A2 在 6.8 万回合里**一次都没成功**，A2 的目标距离甚至**在增大**；同时它们的越界更低（3~4 / 1）、舵角与艏摇更小 ⇒ **安全层确实在起作用，但代价是任务无法完成**。

**结论 3（最严重）：规则学习信号衰减了约 90 倍。**

| 量 | 起始 | 现在 | 倍数 |
| --- | --- | --- | --- |
| 教师发声率（A1） | 0.187 | 0.0275 | **÷6.8** |
| 教师修正幅度（A1） | 0.123 | 0.0092 | **÷13.4** |
| **有效学习信号（两者乘积）** | — | — | **÷≈90** |

> 一句话：**策略越会开船，教练越不开口；即使开口，纠正的幅度也越小。**

### 5.3 诚实的失败清单

| 问题 | 状态 |
| --- | --- |
| **诊断标签坏了 3 个**：raw_to_constrained 恒 0、capture_distance 恒 0.1、landmark error 恒 0.001253 | 待修（会误导后续分析） |

## 6. 卡在哪：两个根因

### 6.1 根因 1：会遇是按本船静止设计的，本船一开起来就散了

**实测证据**：

| 时刻 | 本船速度 p_vel | 3DOF 航速 u |
| --- | --- | --- |
| **回合开始（reset）** | [0, 0] | **0.000** |
| 40~50 步之后 | 0.0058 km/s | **5.824 m/s** |

**机制**：CPA 前推在**回合开始那一刻**读本船状态（此时**静止**）反推目标航向 / 航速，使若双方保持原状态则 DCPA 等于设计值。但本船随后**加速到 5.8 m/s**，相对运动完全改变 ⇒ **设计好的会遇不复存在** ⇒ 规则引擎不判定存在让路义务 ⇒ **教师不发声**。

**这解释了全部现象**：

- 训练最初策略在起点附近**原地打转**（净速度低）⇒ 接近静止假设 ⇒ 发声率 **18.7%**；
- 训练后期策略学会**巡航**（且舵 / 艏摇变小，实测 10.2° → 2.45°、18.4 → 3.2 °/s）⇒ 设计几何失效 ⇒ 发声率 **2.75%**。

> **这不是策略乱探索，恰恰相反：策略越规整、越会开船，规则信号越少。**

### 6.2 根因 2：奖励里的进展项退化成每回合白送的常数

理论上，势函数塑形（PBRS）的回合累计为：

```
Σ[γΦ(s') − Φ(s)] = k·(d₀ − γ^400·d_H)
k = 60, d₀ = 1.1 km, γ^400 = 0.1347
⇒ 60 × (1.1 − 0.1347) ≈ 57.9
```

**实测**：reward_component_progress 三个臂都稳定在 **53 → 57**，**连 A2 目标距离在增大时也是 57**。

⇒ **它几乎与行为无关**：走近目标拿 57，走远也拿 57。
⇒ 于是 A1 / A2 的最优策略变成：**拿白送的 +58，再把越界 / 风险压到接近 0** ⇒ 回报 +21，**但一次都没完成任务**。这是躺平最优的定量证据。

## 7. 怎么往下走

### 7.1 优先级 1（根因修复）：让会遇跟着策略走

| 做法 | 说明 |
| --- | --- |
| **重瞄** | 会遇布置不再用 reset 的瞬时速度，而用**当前巡航速度 / 预测轨迹**反推 |
| **在线重设计** | 会遇未按设计成形时，**周期性重算**目标航向，使其重新对准冲突 |
| **自适应环境** | 把环境难度定义为**当前策略的义务密度 / 失败度**，持续生成处于能力边界的会遇（文献：PAIRED / Prioritized Level Replay / GoalGAN / Reverse Curriculum） |

**优点**：**保持 on-policy**（不放弃真实交互）、**不需要改学习算法**、**能按阈值保证发声率**。

### 7.2 优先级 2：稀有样本重采样（+ 陈旧度控制）

**本质**：重采样等于**目标函数重加权**，**不产生新信息**。

| 风险 | 对策 |
| --- | --- |
| 样本不代表真实会遇到的态，容量押错 | 只用它**补覆盖**，并与主任务损失平衡 |
| **陈旧**：规则池里的态来自旧策略，策略变了就越来越不相关 | **按 age 衰减 / 超龄淘汰 / 定期用当前策略刷新** |
| 与 RL 目标互相拉扯 | 同时监控内化指标与任务指标 |

文献：Prioritized Experience Replay、DDPGfD（显式过采样示范）、HER、Self-Imitation Learning。

### 7.3 优先级 3：设计态 + 教师标签（补覆盖，风险最高）

**做法**：不依赖真实 rollout，直接**构造 N 个存在让路义务的态**，用当前策略在这些态上算模仿损失（标准答案来自规则教师）。

**理论风险（必须正视）**：**状态分布失配**。在**外部固定分布**上做模仿，误差界是 **O(εT²)**；DAgger 之所以是 **O(εT)**，是因为它用**学习者自己的状态分布**。

**因此必须同时满足三条**：

1. **覆盖**：设计态要覆盖存在让路义务的**流形**，不是几个样板；
2. **并存**：保留 on-policy 教师信号，设计态只做补覆盖；
3. **观测一致性**：我们的观测是**体坐标系 + 动作链**（dim 63），**必须复用环境自带的观测编码器**来构造观测，否则训练分布不等于部署分布。

> 附：模仿损失只需要状态 s 与教师答案 a_teacher(s)，**不需要额外拷贝一份网络**。

### 7.4 优先级 4：新增指标——有效发声率

**定义**：发声 **且** 修正幅度大于阈值 δ 的比例。

**理由**：本轮数据显示**发声率 ÷6.8、修正幅度 ÷13.4**；只看发声率会**高估**教师的作用（发声但几乎不改动作，等于没有梯度）。

### 7.5 阶段验收门槛（建议）

| 阶段 | 通过条件 |
| --- | --- |
| **A. 信号恢复** | 发声率稳定不小于 15%（不再随训练单调衰减）；有效发声率不小于 5% |
| **B. 任务不被堵死** | 带安全层的臂成功率不小于 A0 的 1/2 |
| **C. 内化出现** | 撤除过滤器后合规率显著高于 A0；反向动作比显著低于 A0 |
| **D. 可发表** | 3 种子 + 置信区间；A2 / A3 / A4 的消融可解释 |

| 名词 | 一句话解释 |
| --- | --- |
| **COLREGs** | 国际海上避碰规则：谁让谁、怎么让、让多少 |
| **安全过滤器 / 屏蔽层** | 训练期外挂的副驾驶：发现危险就改动作，防止撞船 |
| **规则教师** | 一个按规则算出标准答案动作的程序（不是神经网络） |
| **规则经验池** | 存当时状态 + 教师标准答案的数据库，供策略反复学习 |
| **模仿损失** | 让策略动作尽量接近教师标准答案的惩罚项 |
| **发声率** | 教师认为这一刻存在让路义务、需要纠正的步数比例 |
| **CPA / DCPA / TCPA** | 最近会遇点 / 最近会遇距离 / 到最近会遇点的时间 |
| **内化** | 移除副驾驶后，策略自己依然按规则行事 |
| **势函数塑形 (PBRS)** | 一种理论安全的奖励设计：只改学习速度，不改最优策略 |
| **协变量漂移** | 训练时见过的状态分布不等于实际会走到的状态分布，导致训练好、用起来差 |

## 10. 一句话总结

> **这个项目要证明规则可以被策略内化，而不是规则可以被外挂执行。**
> 现在机制跑通了、任务也证明可学，但**教练开口的次数和力度都在衰减**——因为**会遇是按本船静止设计的，本船一开起来就散了**。
> **下一步不是调参数，是让会遇跟着策略走。**
