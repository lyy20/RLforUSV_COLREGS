## 二、**不成立**的证据（正式撤回）

以下结论**全部撤回**，不得用于论文、答辩或后续推断：

| 被撤回的结论 | 为什么无效 |
| --- | --- |
| 「C 臂（滤波+模仿）最优」 | 阶段不对等（C 训练回合数 2 倍） |
| 「同阶段下 C 反而更差」 | 用的是 **~1100 回合**策略，远未收敛，测的是随机性 |
| 三臂 A0 合规比 / 反向动作比 / 内化成功率的**排序** | 同上；单 seed、无置信区间、事件数少 |
| 「模仿是慢热的」 | 该推断同样建立在未收敛策略之上 |

**根本原因（我犯的方法学错误）**：
1. 项目基线训练量为 **1,200,000 回合**量级，我却用 **~1000 回合**的策略做策略质量评估；
2. **没有多 seed 平均**，无方差与置信区间；
3. 把「训练期基础设施有效性」与「策略学习效果」混为一谈，用后者给前者背书；
4. 连续两次基于噪声得出结论（先「C 最优」、后「C 更差」），且未先质疑测量有效性。

## 三、策略级结论的必要条件（未满足前不得下结论）

| 条件 | 当前状态 |
| --- | --- |
| 训练到收敛（对齐基线量级，≥1e5~1e6 回合） | ❌ 仅 ~1e3 |
| ≥3 seeds，报告 mean ± 95% CI | ❌ 单 seed |
| 评测事件数足够（建议 ≥50~100 事件/臂） | ❌ 4~20 |
| 臂间阶段严格对齐（回合数、配置、评测协议） | ⚠️ 已发现不对等 |
| 结论与「训练期诊断量」分离陈述 | ❌ 曾混用 |

## 四、后续实验计划的约束（待用户指定）

- 策略级比较（filter / filter+模仿 / w_rule 消融）**必须**在收敛量级 + 多 seed 下进行；
- 在此之前，**只报告训练期/机制层诊断量**；
- 任何策略级数字必须标注：训练回合数、seed 数、事件数、CI。
